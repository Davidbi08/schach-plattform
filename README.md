## Chess AI chats

The general chess chat on the home page, the analysis coach, and the tactics coach use the OpenAI Chat Completions API from a server-side route. Set `OPENAI_API_KEY` as a server environment variable in Vercel (and locally in `.env.local`) before using the chats. Never expose this key with a `NEXT_PUBLIC_` variable or commit it. `OPENAI_CHAT_MODEL` is optional and defaults to `gpt-4o-mini`.

Questions and, for the analysis and tactics coaches, the current chess position/context are sent to OpenAI to generate an answer. Chat transcripts are kept only in the current page session by the browser; this application does not persist them.
